# Development Considerations

- The code should seamlessly support desktop, tablet and mobile (portrait and landscape) without requiring dedicated code for each platform.

- Employ CSS only animations unless you recommend otherwise to achieve the desired impact.



# Design Considerations

## One design should seamlessly support desktop, tablet and mobile (portrait and landscape).

## The design should be visual, rather than text, oriented with an emphasis on video and animation; though not overdone.

## Avoid employing LinkedIn inconography including in all video and grahical components.

## Make creative design choices with a focus on:

- Typography: Avoid generic fonts; opt instead for distinctive choices.

- Color & Theme: The overall theme should be light, employ CSS variables for consistency, and employ positive colors with sharp accents.

- Motion: Include animations for effects and micro-interactions that reflect CSS only solutions with a focus on high-impact moments since a few well-orchestrated animations creates more impact than overdone micro-interactions.

- Background: Create atmosphere and depth rather than employ solid colors and keep it light rather than dark.

- Avoid commonly employed AI-generated fonts, color schemes, layouts and patterns.
