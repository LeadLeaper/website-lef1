# Animation Integration Instructions
## `linkedin-email-finder-animated.svg` → LeadLeaper Homepage

---

## What the animation does

After a trigger (scroll or standalone fallback), each of the 7 "+" icons in the
popover sequentially converts to a spinner (400 ms) then a green envelope, top to
bottom, at 400 ms intervals.  The 7th row (Jonathan Richards, partially visible at
the footer boundary) is clipped by `#ll-contacts-clip` so only its top half shows.

---

## SVG script design

The script exposes a single global trigger function:

```js
llStartAnim()
```

- Guarded by `_animStarted` — safe to call multiple times; only fires once.
- A **standalone fallback** (`setTimeout(llStartAnim, 1500)`) auto-fires when the
  SVG is opened directly in a browser, preserving the original demo behaviour.
- When embedded inline in HTML the page's IntersectionObserver calls `llStartAnim()`
  and the fallback timer simply no-ops (guard prevents double-fire).

Timing constants inside the script (easy to tune):

| Constant | Default | Meaning |
|----------|---------|---------|
| `DELAY`  | 1000 ms | Pause after trigger before first spinner appears |
| `STEP`   | 400 ms  | Interval between rows; also spinner display duration |

## Embedding in the HTML page

### 1 — Inline the SVG

The SVG **must** be pasted inline (not `<img>` or `<object>`) so its script shares
the page's `window` scope and `llStartAnim` is accessible.

```html
<section id="virtual-assistant">
  <!-- paste full contents of linkedin-email-finder-animated.svg here -->
</section>
```

Inlining adds ~242 KB to the HTML source — acceptable for a marketing page.

### 2 — Add the IntersectionObserver

Place this script block after the inlined SVG (or in a deferred script at page bottom):

```js
(function () {
  var section = document.querySelector('#virtual-assistant');
  if (!section) return;

  var observer = new IntersectionObserver(function (entries) {
    if (entries[0].isIntersecting) {
      if (typeof llStartAnim === 'function') llStartAnim();
      observer.disconnect(); // fire once only
    }
  }, { threshold: 0.4 }); // trigger when 40% of section is visible

  observer.observe(section);
})();
```

`threshold: 0.4` means the animation starts when 40% of the section has scrolled
into view.  Adjust down (e.g. `0.2`) if the section is tall and you want earlier
triggering.

## Workflow for the Claude Design handoff

1. Complete the UI design in Claude Design.
2. Use **Export to Claude Code** — this drops the updated HTML into
   `projects/website-lef1/claude-code/`.
3. Open a new Claude Code session in that folder.
4. Ask Claude Code to:
   - Paste the inline SVG into the `#virtual-assistant` section of the exported HTML.
   - Add the IntersectionObserver script block above.
5. Test by opening the HTML directly in a browser and scrolling to the section.
